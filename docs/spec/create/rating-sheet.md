# Problem rating sheet

Rater: \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_  Date: \_\_\_\_\_\_\_\_\_\_\_\_

**Why this exists.** I am building software that writes new contest-style problems, from AMC 10 level up to AIME level, plus a few quant-style probability problems. Before I trust it, I need one expert judgement of what a good problem looks like. The 14 problems below mix problems from past contests with machine-generated ones, in an order chosen so that neither kind is grouped, and with no labels. Please don't try to guess the source, and if you recognise a problem, rate it as you would any other.

**Time.** About 30 to 45 minutes; the sheet is two sides. You need not solve every problem completely: read each one, solve or sketch the ones you can, and skim the rest. No answer key is attached. Imagine contest conditions: no calculator, free response (no answer choices).

**How to mark.** For each problem, circle one number from 1 to 5 for each question (1 = no, 5 = definitely):

- **Q1 Well-posed.** Is it unambiguous, with a single correct answer of the stated form?
- **Q2 Difficulty.** Is the difficulty right for the contest and position you wrote under "Feels like"? (5 = about right for that slot; 1 = badly mismatched, too easy or too hard.)
- **Q3 Interesting.** Is it a problem worth solving, rather than a mechanical routine?
- **Q4 Would use.** Would you give it to students?

"Feels like" is optional free text: roughly which contest and position the problem feels like (for example AMC 10 #15, AMC 12 #22, AIME #6). "Comment" is optional: an ambiguity, a different answer, a suggested fix, anything. Leave blank whatever you would rather skip.
