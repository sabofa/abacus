## Shared interfaces

These are defined in T1. Every later agent receives them as signatures only.

```python
# src/abacus/__init__.py
__version__ = "0.1.0"

# src/abacus/config.py: from env, read at call time
@dataclass(frozen=True)
class Config:
    library: Path           # ABACUS_LIBRARY, default <repo>/library
    time_s: float           # ABACUS_TIME_S, 20
    time_max_s: float       # ABACUS_TIME_MAX_S, 600
    mem_mb: int             # ABACUS_MEM_MB, 2048
    network: bool           # ABACUS_NETWORK, off
    max_examples: int       # ABACUS_MAX_EXAMPLES, 10
def get_config() -> Config

# src/abacus/evidence.py
METHODS = {"exhaustive", "sampled", "symbolic", "numeric", "search", "fit", "timed"}
@dataclass
class Evidence:
    button: str; result: Any; method: str; scope: str          # scope must be non-empty
    complete: bool = True; precision: Any = None
    examples: list = field(default_factory=list); compare: dict | None = None
    flags: list[dict] = field(default_factory=list)             # each {"code","message"}
    notes: list[str] = field(default_factory=list); seed: int | None = None
    budget: dict = field(default_factory=dict); kit: str = __version__
    input: dict = field(default_factory=dict)
    def to_dict(self, full: bool = False) -> dict    # jsonable; caps examples unless full
def jsonable(x) -> Any       # sympy → str, Rational/Fraction → "p/q", numpy → python, set → sorted list
def make_compare(proposed, computed) -> dict          # {"proposed","computed","equal"}; no verdict words
# RULE: no field or key named correct / pass / valid / score anywhere (kit/03 §2.1)

# src/abacus/registry.py
@dataclass(frozen=True)
class Button: name: str; fn: Callable[[dict, "Ctx"], Evidence]; description: str
              input_schema: dict; default_time_s: float | None; uses_seed: bool
def button(name, *, description, input_schema, default_time_s=None, uses_seed=False)  # decorator
def get(name) -> Button;  def all_buttons() -> list[Button];  def load_all() -> None  # imports abacus.kit.*

# src/abacus/budget.py
@dataclass
class Ctx:
    seed: int | None; deadline: float                 # time.monotonic() deadline
    progress: Callable[[dict], None]                   # partial {"result","scope","method"}
    def time_left(self) -> float
def call(name: str, inp: dict, *, time_s=None, mem_mb=None, in_process=False, full=False) -> Evidence
    # validates inp (jsonschema; a bad input → Evidence with flag "bad_input", complete False);
    # resolves seed (inp["seed"], else drawn if uses_seed); runs fn in a spawn child unless in_process;
    # on timeout: kill, Evidence(complete=False, result=last partial, scope=partial scope or
    #   "stopped at the time budget before any progress"); budget={"time_s","limit_s","stopped","mem_enforced"}
    # mem cap: RLIMIT_AS on Linux; on Windows mem_enforced=False. An exception in fn → flag "error".
    # Sets Evidence.input = the normalised input, and Evidence.seed.

# src/abacus/parsing.py
def parse_expr(s: str, symbols: Iterable[str] = ()) -> sympy.Expr   # whitelisted namespace only (kit/04 §1 list + sympy funcs)
def compile_code(src: str, *, kind: Literal["expr","func"], name: str | None = None, args: Sequence[str] = ()) -> Callable
    # STD_NS: math, itertools, functools, collections, Fraction, sympy as sp, numpy as np, abacus.kit as ak

# src/abacus/kit/__init__.py: the library surface
def exact(**inp) -> Evidence  # one wrapper per button: budget.call(name, inp, in_process=True)
def budget(name: str, inp: dict, **limits) -> Evidence   # child-process guard (kit/02 §5)
```

## Tasks

Each task lists its subtasks. Ids match the ledger. Every subtask is test-first.

### T1 · Foundation
- **T1.1:** `pyproject.toml` (src layout, console script `abacus = abacus.cli:main`, extras `dev`, `nt`, `solve`), `.gitignore` (`.venv/`, `__pycache__/`, `library/.index.sqlite`, `library/usage.jsonl`), `config.py`, `evidence.py`.
  - **Test:** `tests/test_evidence.py` covers jsonable conversions, the example cap, `make_compare`, and a no-verdict-key check over `to_dict()`.
- **T1.2:** `registry.py`, `parsing.py`.
  - **Test:** `tests/test_registry_parsing.py` covers register/get/all; `parse_expr("factorint(12)")` works; `parse_expr("__import__('os')")` raises; `compile_code` builds an expr and a func.
- **T1.3 (risky: shared contract; gets its own review):** `budget.py` and `Ctx`.
  - **Test:** `tests/test_budget.py`:
    - a registered sleep-loop test button that streams progress is stopped at 1 s, giving `complete False` with the partial result and scope;
    - the seed is drawn and reported;
    - a bad input is flagged;
    - an exception is flagged;
    - `in_process=True` works.

### T2 · Surfaces
- **T2.1:** `cli.py`:
  - `abacus <button> '<json>'` or `--input FILE`, with `--pretty`, `--full` and `--time`;
  - `abacus run FILE` (the sandbox: exec with `ak` imported, under the budget; returns stdout and the last expression's value as Evidence `button="run"`, `method="timed"`);
  - `abacus mcp`;
  - stubs for `algo`, `link`, `mint` and `index` (filled in by T8–T10).
  - **Test:** `tests/test_cli.py` (subprocess or `main(argv)`).
- **T2.2:** `mcp_server.py`, using the `mcp` SDK's low-level `Server`:
  - `list_tools` is built from the registry, plus `run`;
  - `call_tool` → `budget.call` → JSON text.
  - Check the installed `mcp` version's API first.
  - **Test:** `tests/test_mcp.py` calls the handlers in-process; no stdio.
- **T2.3:** `tests/test_surfaces_agree.py`. The registry names, the CLI button subcommands, the MCP tools, and the `### N. \`name\`` headings in `docs/spec/kit/04-buttons.md` must match, except for an explicit `PENDING = {"construct"}`.

### T3 · Buttons: arithmetic and algebra (kit/04 §1–3)
- **T3.1:** `kit/exact.py`.
- **T3.2:** `kit/cas.py`, which notes conditional or unevaluated results.
- **T3.3:** `kit/identity.py` (symbolic, plus numeric at random points with `digits`).
- **Tests:** the known answers in kit/09 §1 for each button, plus one honesty test each.

### T4 · Buttons: counting and discrete math (kit/04 §4–6)
- **T4.1:** `kit/enumerate.py`:
  - every `space` kind;
  - `where`, `sweep`, `group_by`;
  - estimates the space size before running, and flags `space_too_large`;
  - streams progress.
- **T4.2:** `kit/sequence.py`:
  - forms: polynomial (finite differences), linear recurrence (sympy `find_linear_recurrence` or Berlekamp–Massey over ℚ), rational generating function, known sequences (a built-in list), hypergeometric if cheap;
  - `holdout` rule;
  - OEIS behind `config.network`.
- **T4.3:** `kit/counterexample.py`: exhaustive, random or both, with `margin` and closest calls.
- **Tests:** kit/09 §1 known answers; `sequence` notes when holdout is zero; a large space stops with `complete False`.

### T5 · Buttons: probability and quant (kit/04 §7–8)
- **T5.1:** `kit/simulate.py`: mean, ci95, Wilson interval for bools, histogram, `vectorized`, z-score in `compare`.
- **T5.2:** `kit/markov.py`:
  - ops: `absorb`, `hitting`, `stationary` (exact `sympy.Rational` while states ≤ 200, else numpy, and say which); `stop` (backward induction); `game` (scipy `linprog`);
  - chain given as a matrix, or as a `start` state plus a `step` function, explored by search.
- **Tests:** 2 dice = 7; HH = 6 and HT = 4; rock-paper-scissors value 0 with a uniform strategy; a seeded rerun is identical.

### T6 · Buttons: continuous math (kit/04 §9–11)
- **T6.1:** `kit/identify.py` (`mpmath.identify` / `pslq`, default basis; a note when digits < 15).
- **T6.2:** `kit/extremum.py`: `grid`, `multistart` (scipy minimize), `evolution`, and `lagrange` (sympy, small cases only); reports near-optimal points.
- **T6.3:** `kit/numeric.py`: `integral`, `sum`, `product`, `limit`, `root` and `ode`, with mpmath at `digits`.
- **Tests:** γ; min of x + 1/x is 2; ∫e^(−x²) = √π/2 to 30 digits.

### T7 · Buttons: CS (kit/04 §13–14)
- **T7.1:** `kit/difftest.py` (registry name `diff_test`).
  - Strategies come from a whitelisted string spec evaluated against `hypothesis.strategies`, or from a generator function.
  - Disagreements are shrunk.
  - `edge` inputs are included.
- **T7.2:** `kit/growth.py`: median timings, then fit 1, log n, n, n log n, n², n³ and 2ⁿ by least squares; report the best fit, the runner-up and fit quality.
- **Tests:** an off-by-one function is caught with a minimal input; a nested loop fits n².

### T8 · Algorithm format (kit/05)
- **T8.1:** `algo/loader.py`:
  - load a file;
  - validate `META` (id, title, summary, roles, tags, techniques, answer, knobs which may be empty, requires, notes);
  - `algo_hash` (sha256 over the bytes with normalised line endings, first 8 hex characters);
  - `algo/rng.py` (`AbacusRNG` wrapping `random.Random` and `numpy.random.Generator`, both from one seed).
- **T8.2:** `algo/roles.py`:
  - runs `compute`, `check`, `generate`, `demo` and `hand_space` under the budget (generate gets `rng` and `knobs`);
  - the `Instance` dataclass (kit/05 §4; `solution` stays None).
- **T8.3:** `algo/lint.py`:
  - checks: header, roles exist, `requires` installed, determinism, agreement on k seeds, range, spread, cost;
  - a file that won't import returns the Python error verbatim;
  - CLI `abacus algo new|lint|show|list|run`;
  - MCP `algo_lint`, `algo_run`.
- **Tests:** fixture algorithms (good, non-deterministic, disagreeing, out of range, a one-off without knobs).

### T9 · Library (kit/06)
- **T9.1:** `library/store.py` (id ↔ path, list, read, write); `library/index.py` (SQLite FTS5 over the META fields, filters, sorts, `rebuild`).
- **T9.2:** `library/links.py` (`links.jsonl`: add, rm, list, find; `<consumer>:<kind>:<id>` targets kept opaque); `library/usage.py` (`usage.jsonl`, appended on every role run).
- **T9.3:** CLI `abacus algo search|show`, `abacus link add|rm|list|find`, `abacus index rebuild`; MCP `algo_search`, `algo_show`, `link_add`, `link_rm`, `link_find`.
- **Tests:** in a temporary `ABACUS_LIBRARY`.

### T10 · Minting (kit/07) and examples (kit/09 §5)
- **T10.1:** `mint/make.py`:
  - derived seeds;
  - runs the roles and stores their Evidence;
  - a no-op `signals` hook returning `{}` (on hold, kit/08);
  - flags: `duplicate_params`, `duplicate_statement`, `duplicate_answer`, `derivations_disagree`, `out_of_range`, `incomplete`;
  - a summary header line;
  - stops after count×5 attempts;
  - writes `library/batches/<date>-<slug>-<nn>.jsonl`.
- **T10.2:** `mint/review.py` (`keep`/`drop` with a note); `adapters/osmosis.py` (instance → `create_questions` item per kit/07 §4; `explanation` is not set; `source_note`; `idempotency_key` = the batch id; `--family` adds `family_id`); `mint/export.py`.
- **T10.3:** `mint/link.py` (pairs the `created` entries in order, falling back to matching on prompt; writes `minted` links `osmosis:q:<lineage_id>`).
  - Three example algorithms in `library/examples/`: an NT family with an AIME-style integer answer; a probability family whose `check` uses `simulate`; a checker-only algorithm.
  - An end-to-end test against a recorded `create_questions` response fixture.
- **Tests:** `tests/test_mint_e2e.py` plus unit tests.
