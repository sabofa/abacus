**Open: T6 (`numeric`) has one Important finding that is a confident wrong answer.**
- `numeric(integral, "exp(-(x-5000)**2)", -oo..oo, digits=20)` returns value 0, 20 reliable digits, `complete` True, no flag (the true value is sqrt(pi)). The same happens for `(x-1000)` over -oo..oo and `(x-5000)` over 0..oo.
- Cause: the geometric splits stop at 2^11 and 3^7, so a narrow peak far from the origin is never sampled. The code before `7793247` returned `no_convergence` for these.
- Suggested fix: flag `zero_from_unsampled_tail` and withhold the value when an infinite-range integral comes out ~0 with an error far below the integrand's scale, or extend the reach to ~1e4.
